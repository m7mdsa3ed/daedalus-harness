Composer strip prototypes

Three ways to surface transient composer items. Each prototype uses the same sample files, prompt history, and project command so the selector treatment is the only variable.

Click a selector inside a prototype to switch its content. Press d to flip light/dark.

C5

Text tabs

Most discoverable

Persistent labels and counts make every available item explicit. Best for first-time clarity; uses the most rail width.
C6

Icon tiles

Compact rail

Counts stay visible on each icon while the active item's label sits beside the controls. Efficient, but relies on icon recognition.
C7

Summary chips

Quieter chrome

Names and counts combine into small pills, reducing the feeling of a traditional tab bar while keeping destinations readable.

Starting recommendation: C5 for clarity, C6 if narrow-panel density is the priority, or C7 if the strip should visually recede.
